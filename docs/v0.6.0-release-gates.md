# v0.6.0 implementation and release gates

**Status: NOT READY FOR NAS DEPLOYMENT.** Stable v0.5.5 remains the release version.

## Mandatory security gates
- [ ] Test authenticated HTTPS + CSRF web-to-privileged-helper boundary, fixed operations, no user-supplied paths, no secrets in URLs/logs/argv/JSON.
- [ ] Verify PHP-FPM identity and helper permissions on EX4100; root-only PHP is not privilege separation.
- [ ] Verify root-owned executable identities for cryptsetup, mount and umount; reject writable binaries and unsafe symlinks.
- [ ] Verify mountpoint ownership, no symlinks, stable mountinfo, and escaped mountpoint paths.
- [ ] Verify mapper UUID, ancestry, kernel device identity, mount aliases and registry ownership under the same lock.
- [ ] Test process timeouts and reaping; never automatically retry ambiguous failures.
- [ ] Confirm cryptsetup 2.3.7 stdin passphrase semantics on disposable LUKS1 storage.

## Functional gates
- [ ] Unlock and Lock; Mount and Unmount, including locked-disk explicit unlock-and-mount.
- [ ] Secure mount directory creation.
- [ ] Inactive-only registration edits; disconnected and connected deletion, including key retirement.
- [ ] Optional stored keys: recovery verification, keyslot addition, root-only storage, backup exclusion.
- [ ] Encrypt + ext4 with two confirmations, exact second text “Are you sure? Your data will be permanently lost!”, three manual attempts maximum and internal disk exclusion.
- [ ] Authenticated web operation integration and browser regression tests.
- [ ] Upgrade and rollback tests from v0.5.5; preserve private configuration.

## Acceptance
- [ ] All PHP and browser CI checks green on final feature commit.
- [ ] EX4100 disposable USB testing: LUKS1 AES-CBC-ESSIV:SHA256 256-bit and ext4, reconnect, aliases, reboot, timeout and failures.
- [ ] Independent review of destructive paths.
- [ ] Package and inspect v0.6.0 only after NAS acceptance; seek explicit approval before merge or tag.

GitHub CI passing is necessary but does not establish NAS safety.
